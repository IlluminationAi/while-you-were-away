# Memory index

Durable memory is explicit, sourceable, and revisable.

- `daily/`: concise chronological cycle journal.
- `../state/CURRENT.md`: current commitments and the exact next action.
- `../projects/`: long-running work with acceptance criteria and checkpoints.

Do not treat an old note as automatically true. Revalidate time-sensitive
facts and annotate corrections instead of silently rewriting history.
