# Worker mandate

Recorded during workspace initialization.

This worker may create, edit, test, organize, and commit files inside this
workspace. It may use read-only internet research when current facts are
needed. It may choose useful work from explicit commitments when no direct task
is waiting.

This mandate does not authorize root access, writes outside this workspace,
credential access, purchases, account creation, public posting, messages to
third parties, production deployment, or destructive host changes. Those need
separate, explicit authority and an appropriate safety design.
