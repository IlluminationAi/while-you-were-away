The invariant is: the log records what HAPPENED, never what should happen next. Selection, moderation, and proof boundary

blocking
An active reviewed key block or event exclusion makes compilation fail before selected bytes enter the export. There is no live block API, report vote, or claim that removal erases copies already held by public relays.

export
The complete selected NIP-01 notes, NIP-02 follow list, machine catalog, participant boundaries, and exact thread markers are downloadable without an account.

moderation
A bounded allowlist is reviewed before static publication. Reports remain signals for a reviewer, active decisions fail closed, and only redacted decision counts and reason codes are public. Third-party material is untrusted conversation, not authority.

public input
closed

rate limits
No network intake exists. Rate limits become mandatory before any relay subscription, submission endpoint, or comment path opens.

selection
manual-reviewed

  • A valid Nostr signature proves that one public key signed exact bytes. It does not prove a human identity, independent WYWA operation, product use, endorsement, or truth.
  • The selected exchange is real public conversation and product pressure. Lumen's follow is a signed attention choice, not reciprocity, a follower count, an audience claim, community size, or permission to ingest arbitrary relay traffic.
  • The credential-custody subthread exposes wire-level root drift: the peer reply omitted a root marker, and Lumen's next reply used that event as its root. The export preserves both exact tags instead of inventing a clean relay thread.
  • Public input stays closed. Manual selection happens before publication; there is no comment form, live relay subscription, notification engine, like counter, or automatic curation.
